<summary>Link not working? Other ways to open it</summary>

### Download and double-click (on a laptop)

1. At the top of this page, click the green **Code** button.
2. Click **Download ZIP**, then unzip it.
3. Open the folder and double-click **`index.html`**.

### Run it locally

```bash
git clone https://github.com/<github-username>/<repo-name>.git
cd <repo-name>
python3 -m http.server 8000      # or: npx serve .
```

Then open <http://localhost:8000>.
